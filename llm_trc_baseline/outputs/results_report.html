💡 Key Findings

What beats the encoder and what doesn't

  • LoRA fine-tuned LLMs beat the encoder — 14B (+7.2 F1), 7B QA1 (+5.5 F1), 7B P (+4.4 F1). Fine-tuning on the training set is the decisive factor.
  • All ICL (zero/few-shot) settings fail to match the encoder — best ICL is 72B/14B QA2 k=0 at 0.702, still 8.5 pts below encoder.
  • Bigger model ≠ better at ICL — 72B ICL (0.719 best) barely outperforms 7B ICL (0.699 best). Model size matters much less than fine-tuning.
  • Few-shot (k=2) is usually worse than zero-shot (k=0) — adding examples hurts on most models/prompts, especially CoT.
  • QA2 prompt is best for ICL; QA1 is best for LoRA — the dual-question consistency check helps zero-shot but LoRA learns yes/no directly.
  • Rationale generation (LLMERE) does not help — rationale LoRA (0.768) is worse than label-only LoRA (0.842). Generating reasoning first costs capacity.
  • AJO is the hardest source across all methods (peak 0.751 with 14B LoRA); AEP is easiest (peak 0.899).
  • Per-event O(n) approach achieves 2.84x fewer LLM forwards at comparable accuracy (F1=0.765) — efficiency win.
