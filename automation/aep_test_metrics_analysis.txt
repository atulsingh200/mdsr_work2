9. TRAINING SAMPLE COUNT vs TEST ACCURACY CORRELATION
--------------------------------------------------------------------------------
  Spearman rank correlation (rho):  UNDEFINED

  All 45 training counts are exactly 1,500 (constant predictor). The Spearman
  correlation cannot be computed for a constant. This is a feature, not a bug:
  the data generation capped every pair at 1,500 and all pairs hit that cap,
  meaning the AEP corpus provides at least 1,500 training samples for every
  tier combination. There is no data-starved pair in this dataset.

  This is structurally different from the AJO dataset where pairs like T1-T2
  (112 train) and T13-T14 (160 train) were severely under-represented.

  Observation: With uniform train counts, accuracy variance is driven entirely
  by content distinguishability. The 0.79-1.00 accuracy range is therefore a
  direct measurement of how semantically separable each tier pair is — not
  confounded by data volume.

10. KEY FINDINGS
--------------------------------------------------------------------------------
  1. OVERALL: 92.4% accuracy — strong performance with no catastrophic pairs.
     The perfectly balanced test set (188 per pair) makes this a reliable estimate,
     unlike datasets with n=2 pairs that produce meaningless 0.00 or 1.00 values.

  2. MONOTONIC GAP TREND: Accuracy increases cleanly with tier gap (0.85 at gap=1
     to 0.99 at gap=10), confirming the model learns real ordinal signal in the
     AEP dependency hierarchy. No anomalous dips — the trend is the smoothest
     seen across any run in this project.

  3. NO CATASTROPHIC TIER: Every tier achieves per-tier accuracy above 0.89.
     The AEP corpus does not have a T14-equivalent — a tier so sparse or
     semantically overlapping that it drags accuracy to near-zero. This is
     the single biggest structural advantage of AEP over AJO.

  4. T5 (IDENTITY FOUNDATION) IS ENTIRELY MISSING: The tier is defined in the
     AEP hierarchy but has zero segments in the corpus. All 10 pairs that would
     involve T5 (T1-T5, T2-T5, T3-T5, T4-T5, T5-T6, ..., T5-T11) are absent.
     The 92.4% accuracy is computed over 45 pairs, not 55. If T5 data were added
     it could hurt performance significantly if Identity Foundation docs borrow
     language from both Data Storage (T4) and Profile & Segmentation (T6).

  5. EARLY-PIPELINE TIERS (T1–T4) ARE THE WEAK CLUSTER: T1-T2 (0.78) and T2-T3
     (0.79) are the only pairs below 0.80. Platform Foundation, Data Architecture,
     and Data Collection are described together in AEP onboarding documentation —
     the tier boundary is real architecturally but not reflected in language.

  6. TRAIN DATA IS NOT THE BOTTLENECK: All pairs have 1,500 training samples yet
     T1-T2 sits at 0.78 and T2-T8 sits at 1.00. The spread is driven by content
     separability, not data volume (Spearman rho is undefined due to constant counts,
     but visually: high train everywhere, yet accuracy ranges 0.78-1.00).

  7. ADJACENT PAIRS (0.85) LAG NON-ADJACENT (0.94) BY 9pp: The hierarchy captures
     real dependency ordering — the model finds it easier to distinguish tiers that
     are architecturally far apart. This is consistent across all runs in this project.

  8. OVERFITTING SIGNAL IN TRAINING: Train loss drops to 0.0125 by epoch 3 while
     val loss rises from 0.2576 to 0.3275 — a 26x train/val loss gap. Val accuracy
     still improves (0.9305 → 0.9499) because the task is learnable enough that
     memorized patterns transfer, but calibration is degrading. The model is becoming
     overconfident. Epoch 1 may generalize better to truly unseen documents despite
     the lower val accuracy.
